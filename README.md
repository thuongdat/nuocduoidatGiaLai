# Tài nguyên nước dưới đất Tỉnh Gia Lai

Trang WebGIS thể hiện các lớp điều tra, đánh giá tài nguyên nước dưới đất:
tầng chứa nước, trữ lượng, chất lượng, vùng nhiễm mặn, vùng ô nhiễm, vùng hạn
chế khai thác, giếng khoan, giếng đào, lỗ khoan địa tầng và trạm quan trắc.

Xem trang: https://thuongdat.github.io/nuocduoidatGiaLai/

Dữ liệu hiện chỉ phủ phần Bình Định cũ. Trang là HTML, CSS và JavaScript
thuần, không có bước build. Chạy trên máy:

```bash
python -m http.server 8000
```

rồi mở http://localhost:8000/

Kho này là bản đóng gói, sinh tự động từ dự án WebGIS tài nguyên nước
Tỉnh Gia Lai. Đừng sửa trực tiếp ở đây: lần đóng gói sau sẽ ghi đè.
